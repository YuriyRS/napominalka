# Сервер-будильник

Маленькая программа: разбудить телефон в назначенную минуту.

**Чего в ней нет — и это её главное свойство.** Ни одного названия дела,
ни одной заметки, ни одной голосовой записи. Она хранит адрес подписки
и список времён, и отправляет обратно **номер дела** — случайную строку.
Что за дело, знает только телефон: он находит его у себя и показывает.
Утечка из этой программы не стоит ничего, потому что терять ей нечего.

## Что нужно купить

| Что | Сколько | Зачем |
|---|---|---|
| **VPS в России** | 200–400 ₽/мес | TimeWeb, Beget — любые. Хватит самого маленького: 1 ядро, 1 ГБ |
| **Имя для него** | 0 или ~700 ₽/год | Без имени не будет HTTPS, а без HTTPS приложение к серверу не постучится |

Про имя подробнее, потому что это неочевидно. Приложение живёт на `https://`,
и браузер запрещает ему обращаться к `http://` — это называется смешанным
содержимым и блокируется наглухо. Значит, серверу нужен сертификат, а сертификат
выдаётся на **имя**, не на адрес. Взять его можно так:

- **бесплатно** — `duckdns.org` даёт поддомен вида `напоминалка.duckdns.org`,
  сертификат на него выдаётся обычным порядком. Имя некрасивое, работает честно
- **~700 ₽/год** — своё имя. Разумно взять, если приложение пойдёт к людям:
  оно понадобится и для RuStore, и вообще

Хостинг обязан быть российским: по 152-ФЗ данные россиян хранятся в России.
Пусть здесь и не данные, а только времена — правило простое, а нарушать его дорого.

## Что поставить на сервер

```bash
# Node 22 или новее — в проекте нет зависимостей, но нужен встроенный WebSocket
curl -fsSL https://deb.nodesource.com/setup_22.x | bash - && apt install -y nodejs

# Caddy — он держит HTTPS и сам продлевает сертификат
apt install -y caddy
```

## Как разложить

```bash
# 1. Код. Публичный репозиторий, ключей в нём нет — их кладём отдельно
git clone https://github.com/YuriyRS/napominalka.git /opt/napominalka

# 2. Ключи VAPID. Тот же файл, что лежит на домашней машине, —
#    он один на всех: подпись должна быть та, к которой привязана подписка
scp ~/napominalka-vapid.json root@сервер:/root/

# 3. Права: читать ключи должен только сервер, больше никто
chmod 600 /root/napominalka-vapid.json
```

> **Ключи — единственный секрет в этом хозяйстве.** Кто их знает, тот может
> слать пуши на телефон. Поэтому они не в git (репозиторий публичный),
> лежат только на машине и на сервере, и с правами `600`.

## Как запустить

`/etc/systemd/system/napominalka.service`:

```ini
[Unit]
Description=Напоминалка — сервер-будильник
After=network.target

[Service]
ExecStart=/usr/bin/node /opt/napominalka/server/server.mjs
Environment=PORT=8081
Environment=DATA=/var/lib/napominalka/data.json
Environment=VAPID=/root/napominalka-vapid.json
Environment=TZ=Europe/Moscow
StateDirectory=napominalka
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
systemctl enable --now napominalka
systemctl status napominalka
```

`TZ` — не мелочь: времена с телефона приходят как точные отметки времени,
но в журнале сервера по этому поясу видно, во сколько он на самом деле
кого разбудил. Без него журнал будет во времени сервера, и сверять станет
нечем.

`/etc/caddy/Caddyfile`:

```
напоминалка.duckdns.org {
    reverse_proxy 127.0.0.1:8081
}
```

```bash
systemctl reload caddy
```

Caddy сам получит сертификат и сам будет его продлевать. Сервер при этом
слушает обычный `http` и уверен, что стоит за прокси, — так проще,
чем городить шифрование внутри программы.

## Как проверить

```bash
curl https://напоминалка.duckdns.org/health
# {"ok":true,"devices":0}
```

`devices` — сколько телефонов подписалось. Ноль сразу после установки — так и должно быть.
Это же число и есть честный ответ на вопрос «сколько людей этим пользуются»:
считать больше нечего и не нужно (§13.10 плана).

## Что сказать приложению

В `app.js` есть строка:

```js
const SERVER = '';   // адрес сервера-будильника; пусто — напоминаний нет
```

Вписать туда `https://напоминалка.duckdns.org` — без косой черты на конце.
После этого в настройках приложения появится строка «Напоминания»
с кнопкой «Включить».

Пока строка пуста, приложение работает как обычно: оно вообще не зависит
от сервера, просто не напоминает.
