# Напоминалка

PWA-приложение-напоминалка. Сначала для одного человека, дальше — для друзей.

**Весь план лежит в `ПЛАН.md` в этом же каталоге — читать в начале каждой сессии.**
Раздел 12 там всегда показывает, на каком этапе проект. Этот файл намеренно короткий,
чтобы не дублировать план и не расходиться с ним.

## Жёсткие рамки — не нарушать

- **Только PWA.** Никаких нативных приложений и магазинов на этом этапе: у пользователя
  медленный интернет (25–35 КБ/с), 8–10 ГБ Android Studio скачать нереально.
- **Данные — на телефоне.** Задачи не покидают устройство. На сервере (если появится)
  только время пробуждения, без содержимого.
- **Не делаем:** геозоны, звонок вместо уведомления, платежи, регистрацию, синхронизацию.
  Причины — в `ПЛАН.md` §9.
- **Экспорт в файл обязателен с первого этапа** — иначе данные умрут вместе с телефоном.

## Стек

HTML / CSS / JS, IndexedDB, service worker, манифест. Системный шрифт.
Никаких фреймворков и сборщиков: у пользователя медленный интернет, лишние зависимости
скачивать нечем, а проект по размеру этого не требует.

## Запуск и отладка

```powershell
npx serve .    # из папки проекта
```

Ещё есть стенд в `tools/` — поднимает статику сам, кладёт демо-задачи,
снимает экран, кликает по нему и проверяет выкладку в подкаталоге.
`node tools/shoot.mjs обычный`, `node tools/check.mjs`, `node tools/deploy.mjs`.

Проверка на телефоне — §11 в `ПЛАН.md`. Для service worker и уведомлений нужен HTTPS.

## Стиль работы

Перед правкой файлов, которые пользователь не просил менять, — спросить одной строкой.
Объяснять коротко, без лекций. Подробности — в глобальном `~/.claude/CLAUDE.md`.
